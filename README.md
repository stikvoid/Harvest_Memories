# 🌾 Harvest Memories

**Harvest Memories** es un juego interactivo que honra la memoria, la resistencia y los rituales cotidianos de la vida colombiana. Cada mecánica, cada espacio, cada símbolo —desde el café hasta las velas— está diseñado para cosechar recuerdos y sembrar luz.

---

## 🧠 Concepto narrativo

En *Harvest Memories*, el jugador recorre una finca modular, reconstruyendo fragmentos de historia familiar a través de objetos simbólicos.  
- **El café** representa el trabajo, la herencia y la conexión con la tierra.  
- **Las velas** iluminan la memoria, los rezos y los silencios compartidos.  
- **El fuego** transforma el dolor en ritual, y el olvido en resistencia.

Este juego es un ritual digital para resistir la oscuridad y celebrar la humanidad.
